# will-escrow TypeScript client

Generated by [Codama](https://github.com/codama-idl/codama) from
`programs/will_escrow/idl/will_escrow.json`, for `@solana/kit`.

```ts
import { findJobPda, getCreateJobInstructionAsync } from '@applied-will/will-escrow';

const instruction = await getCreateJobInstructionAsync({
  customer, customerToken, rentPayer, mint, // config, job, vault and programs are derived
  jobId: 1n, budget: 20_000_000n, jobKind: 0, adapter: 1, mandateCap: 0n, mandateExpiresAt: 0n,
});
const [job] = await findJobPda({ customer: customer.address, jobId: 1n });
```

- `npm run codegen` regenerates `src/generated` after the IDL changes.
- `npm test` builds and checks the client against byte vectors the Rust tests
  write (`programs/will_escrow/tests/vectors`), and that `src/generated` is
  current.

`scripts/codegen.mjs` adds what the IDL does not carry: PDA helpers, default
accounts (config, job, vault, token and system programs, ProgramData), account
tags and sizes, and hidden instruction discriminators.
