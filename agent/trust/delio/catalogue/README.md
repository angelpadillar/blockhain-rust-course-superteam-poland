## Refresh

Run `node agent/trust/delio/refresh-groceries.mjs` from the actual repository, with the required private configuration present locally; the workspace copy is `node trust-layer/delio/refresh-groceries.mjs`. The fixed SSH transport uses only the isolated `buena-delio-worker`. A refresh reads the homepage, then at most one observed promotions path; it never clicks Add, Checkout or Buy. It requires the saved address header still to match Kraków, and preserves the previous published dataset on an unsuccessful refresh. The source config and private profile remain server-side. No arbitrary URL/selector/code is accepted by the new worker operation.

Classification is cached by product text, model and taxonomy. Its private ledger reserves each call before dispatch, includes failed calls, and has a persistent six-call cap for this pilot. Unchanged names use the cache free of further inference; new/changed products beyond the cap stay unclassified. Interrupted pending calls require review, not automatic retry. The category probabilities are not an eligibility or stock signal.

The collector reads rendered HTML through the existing browser adapter. Whole signed-in pages are not copied to the workstation: extraction runs inside the worker and returns only product fields, safe category links and evidence hashes. It uses the merchant's observed product-content container and waits for cards. There is no hidden API/session scrape and no new browsing host permission.
